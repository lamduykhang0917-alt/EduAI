Ghi chú tích hợp AI

Chatbot hiện được cấu hình để gọi trực tiếp Claude hoặc Gemini nhằm trả lời tự do bất kỳ câu hỏi nào của sinh viên, không giới hạn trong dataset nội bộ. Cần cấu hình API key trong file backend/.env (sao chép từ .env.example). Nếu chưa có key hoặc gọi API lỗi, hệ thống tự động dùng dữ liệu nội bộ (dataset) để trả lời tạm, không bị gián đoạn.
